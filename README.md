# Telve

A deck-building roguelike themed around Turkish coffee fortune-telling.
Balatro's "one deck, endless combos" loop combined with the narrative
power of fortune-telling culture.

- **Engine**: Unity (2D URP)
- **Target platform**: mobile (iOS/Android)
- **Core loop**: flip the cup → symbols appear → arrange them into a
  reading order → combos trigger → score / customer payment

See [`ROADMAP.md`](ROADMAP.md) for the full development plan and current
progress.
